# Lenormand Oracle Web

個人向けルノルマンカードWebアプリのソースコードです。カード画像・カード意味・ルールのデータは公開リポジトリに含めません。

## ローカルで起動

1. Node.js 22以降を用意します。
2. `private-assets/` に `cards/01.png`〜`cards/36.png`、`cards_db.json`、`rules_db.json` を配置します。
3. `npm ci` を実行します。
4. `npm run dev` を実行し、表示された画面を開きます。

Windows版のカード素材をコピーする例:

```powershell
./scripts/prepare-private-assets.ps1 -SourcePublicDir 'C:\path\to\webapp\public'
```

このスクリプトはViteのローカル表示用`public/`と、デプロイ用`private-assets/`の両方へコピーします。両方のパスはGitから除外されます。Dockerの本番ビルドでは`public/`をビルドへ取り込まず、Composeが非公開素材を認証済みサイト領域へ配置します。

## ホスティング状況

現在のコードはローカルNode.jsサーバーで動作します。本番用のホスティング先は未設定です。

ChatGPTプラン連携には、トークンを安全なサーバー側に保管・更新する必要があります。OpenAIのOSS向け手順はローカルアプリと自己管理VMを説明し、トークンをブラウザー保存・ログ・ソース管理へ置かないよう案内しています。リモートホスト型アプリ向けのChatGPTサインインは別の限定試行として案内されています。GASをそのまま使える根拠は確認できていないため、GASへ認証情報を送る処理は実装していません。

OCIなどのVMは本人確認でカード登録を求める場合があり、利用者はカード登録を避ける方針です。カード登録や有料化へ自動で進まないでください。Docker、Caddy、暗号化バンドル関連のファイルは自己管理VM向けの準備物ですが、現在のユーザー環境では未デプロイです。

現在のGAS試作は、画面表示と非公開Drive素材の配信までを確認するためのコードです。ChatGPT自動生成は未対応で、Webアプリとしてデプロイしての動作確認も未完了です。履歴は端末ごとの`localStorage`保存で、端末間同期はありません。

指定条件（ChatGPTプラン、追加料金なし、カード登録なし、追加サーバーなし）をすべて保ったままの自動読み解き経路は、まだ確立できていません。GASの現状と使い方は [`gas-prototype/README.md`](./gas-prototype/README.md) を参照してください。

## 保存とプライバシー

- リーディング履歴はブラウザーごとの`localStorage`に保存され、端末間で同期しません。
- カード画像、カード意味、ルール、生成結果は公開コードに含めません。
- ChatGPTへ送るのは選択したカードの意味、展開情報、入力した質問です。
- `.env.production`、`private-assets/`、`private-secrets/`、認証JSON、移行バンドル、VMデータをGitへ追加しないでください。

## 現在の制約

- OCI Always Free VMは作成時の空き容量が保証されず、低稼働VMが回収対象になる場合があります。
- 本番環境の非公開デプロイ、ChatGPT認証情報のVM移行、HTTPS、iPhoneからの利用は、実環境で確認するまで未検証です。
- 初回公開ソースは、公開前の秘密情報・依存関係・ライセンス確認が必要です。
